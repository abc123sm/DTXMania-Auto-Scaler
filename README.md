# DTXMania Auto-Scaler

这是一个为 DTXMania 谱面自动生成低难度版本的脚本工具。主要用于处理只有高难度原谱的歌曲，通过合理的删减规则，为新手和进阶玩家提供可供练习的阶梯难度谱面。

## 主要处理规则

1. **小节内乐器种类限制**：针对新手读谱容易眼花的问题，限制单小节内出现的鼓件种类（**左右脚不计入该统计**，仅统计手部乐器）。例如在 BASIC 难度中，一小节最多只保留 1 种手部乐器，大幅减少视觉干扰。
2. **脚部踏板简化**：
   - **BASIC (L1)**：一个小节内，最多只能出现 1 个脚部动作。
   - **ADVANCED (L2)**：一个小节内，最多允许出现 2 个脚部动作，且严禁左右脚同时踩（若遇到同时踩击，则自动剔除左脚）。
3. **密度与疲劳控制**：在 ADVANCED 难度中，虽然允许保留 8 分音符，但如果检测到连续出现过多包含 8 分音符的小节，系统会将其强制削减为 4 分音符，防止新手因长时间高密度敲击而疲劳。
4. **原文件保护机制**：脚本会通过识别 `set.def` 中的 `#TITLE (AI mode)` 标记来判断文件是否由本程序生成。遇到原作者自带多难度谱面的歌曲时，脚本会自动跳过处理，防止误覆盖原文件。

## 难度分级 (L1 - L5)

脚本会将原谱转换为包含 5 个难度的 `set.def` 配置，方便在游戏中切换：

| 级别 | 标签 | 阶段 | 手部限制 | 脚部限制 | 小节内最多手部鼓种类 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **L1** | BASIC | 新手基础 | 4分音符，同拍最多 1 手 | 小节内最多 1 个脚 | 1 种 |
| **L2** | ADVANCED | 进阶练习 | 8分音符 (过多则降为4分)，同拍最多 2 手 | 小节内最多 2 个脚 (禁止同时踩) | 2 种 |
| **L3** | EXTREME | 手脚协调 | 8分音符，同拍多手解禁 | 适度引入更密集的脚部 | 3 种 |
| **L4** | MASTER | 困难挑战 | 滤除过于密集的爆发段落 | 同手部 | 5 种 |
| **L5** | MASTER+ | 原版谱面 | 完整保留原作者谱面 | 完整保留 | 无限制 |

## 包含的文件

* `simplify_dtx.py`：谱面降级处理主脚本。生成的文件统一使用 `_aimode_xxx.dtx` 后缀。
* `analyze_dtx_level.py` & `analyze_left.py`：数据分析脚本，用于统计和参考常规低难度谱面的音符密度规律。

## 使用方法

在命令行中运行脚本并指定要处理的曲库目录：

```bash
python simplify_dtx.py "C:\你的曲库路径\くだむのDTXおきば"
```
